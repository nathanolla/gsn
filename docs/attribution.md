# Image attribution manifest

Images are **minimal by doctrine** (§9): a map plus data cards barely needs photos, and
every image is weight plus provenance risk. Where used: in-house, public domain, or
open-licensed only — recorded here (path → source → license) so compliance is auditable.
No hotlinking, no found-on-Google, no manufacturer press assets.

CI enforces: every image in the repo must (a) carry zero EXIF metadata and (b) appear in
this manifest.
